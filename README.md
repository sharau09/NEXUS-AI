# 🚀 NEXUS AI
## Autonomous AI Operations Intelligence Platform

NEXUS AI is an end-to-end AI-powered AIOps platform that monitors infrastructure, detects anomalies, classifies incidents, identifies probable root causes, predicts incident risk, analyzes logs, correlates operational events, and assists engineers through an AI Incident Copilot.

## ✨ Features

- Real-time infrastructure monitoring
- CPU, memory, API latency and error-rate monitoring
- ML-based anomaly detection
- Incident severity classification
- Root cause analysis
- Incident risk prediction
- Intelligent log analysis
- Incident correlation
- RAG-based evidence retrieval
- Local LLM Incident Copilot
- Investigation history
- Automatic incident detection
- Smart alert generation
- FastAPI backend
- Streamlit dashboard
- Docker deployment
- Automated testing

## 🧠 AI/ML

NEXUS AI combines:

- Scikit-learn
- TF-IDF
- KMeans clustering
- Random Forest
- Cosine similarity
- Retrieval-Augmented Generation
- Llama 3.2 through Ollama
